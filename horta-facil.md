# Horta Fácil

Interface web para organização do cultivo de plantas, feita em HTML, CSS e JavaScript puro, sem frameworks e sem bibliotecas externas.

Projeto final do curso de Front-end do Instituto Hardware Brasil. Há a possibilidade de aplicação em uma horta comunitária de Alvorada, RS, ainda em conversa.

**Site:** https://kethlynmartinez.github.io/horta-facil/ · [Protótipo no Figma](https://www.figma.com/proto/XZM2zIkmlUjVVchYq7Xvcg/Horta-F%C3%A1cil---Mock-Site?node-id=3-2)

## Páginas

- Início
- Catálogo com 134 espécies
- Cadastro e login
- Recuperação de senha (simulada)
- Área logada
- Gerenciamento de canteiros (criar, editar e excluir)

## Como testar

Acesse o site, ou abra o `index.html` no navegador (também funciona com a extensão Live Server do VS Code).

Usuário de demonstração:

- E-mail: demo@hortafacil.com
- Senha: 123456

## Observações

A autenticação é simulada: usuários cadastrados ficam salvos no `localStorage` do navegador, sem servidor. Os canteiros ficam apenas em memória e reiniciam ao recarregar a página.
